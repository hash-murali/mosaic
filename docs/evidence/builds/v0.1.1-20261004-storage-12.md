## Implemented and inspected

Encrypted source blobs, metadata and FTS in SQLCipher; durable receipt/pending stage, dedupe, transactional correction/delete, revisions, bounded queries and bound text including embedded NUL. Wrong keys, ciphertext modification and missing selected directory fail closed in synthetic fixtures. Snapshot uses SQLCipher backup with an independent key, verifies integrity and closes destination before publication; existing destinations are not replaced.

ProtectedVault validates explicit record/field/operation scope and performs synchronous database operations on the same actor as policy state. Lock closes the database and invalidates authority. Tests verify a queued stale write after lock cannot commit, wrong identity cannot reopen, FTS returns only scoped IDs and duplicate receipt cannot disclose an out-of-scope existing ID. This fixes an issue discovered during scoped source review; it is not a full formal security review.

Image intake checks 25 MiB encoded bytes, 30 million pixels, PNG/JPEG actual type and single-frame decode; EXIF normalization is implemented. Session retention has a 256 MiB/32-record bound. Dimension/overflow and invalid-data tests pass; encoded-format/orientation fixture tests, aggregate peak-memory/fault/cancellation evidence remain pending. HEIC/TIFF are disabled with TODOs.
